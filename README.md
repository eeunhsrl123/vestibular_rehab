# 균형일상

전정신경염 진단 후 의료진과 정한 재활을 꾸준히 실천하고 기록하는 한국어 개인용 사이트입니다.

- 시선 안정화·균형·걷기 운동 안내
- 시간 설정, 일시정지·이어하기가 가능한 운동 타이머
- 어지럼 정도(0–10), 메모, 날짜별 운동 완료 기록
- JSON 기록 내보내기 및 전체 삭제
- 모바일 대응 화면과 의료 참고 자료
- 고정 표적, 공 따라보기, 방향키·터치로 조작하는 바운스볼 게임 공간

## 실행

별도 설치나 빌드 없이 정적 서버로 실행합니다.

```sh
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다. GitHub Pages 등 정적 호스팅에서도 저장소 루트를 배포하면 됩니다.

## 검증

Node.js 20 이상에서:

```sh
node --test tests/*.test.mjs
node --check app.mjs
```

## 기록 저장

기록은 현재 브라우저의 localStorage에만 저장됩니다. 서버로 전송하거나 기기 간 동기화하지 않습니다. 브라우저 데이터 삭제, 다른 브라우저·도메인 사용 시 기존 기록을 이용할 수 없으므로 필요한 기록을 내보내서 보관하세요. 내보낸 파일의 재가져오기는 지원하지 않습니다.

## 의료 안내

이 사이트는 개인 기록과 교육을 위한 도구이며 진단이나 개인별 운동 처방을 제공하지 않습니다. 운동 종류·시간·강도는 의료진과 정하세요. 응급 증상과 운동 중단 안내는 사이트의 안전 안내를 확인하세요.

참고 자료:
- [ANPT/APTA 전정재활 임상진료지침](https://pmc.ncbi.nlm.nih.gov/articles/PMC8920012/)
- [NHS 전정신경염](https://www.nhs.uk/conditions/labyrinthitis/)
- [NHS 어지럼과 진료 안내](https://www.nhs.uk/conditions/vertigo/)

## 게임 공간

`games.html`에서 세 가지 모드를 사용할 수 있습니다. 자동 시작하지 않으며, 화면을 떠나면 일시정지됩니다. 방향키 또는 A·D 키, 터치 버튼으로 바운스볼을 조작합니다.

고정 표적 모드는 전문가에게 배운 운동을 돕는 도구이며 움직임을 측정하지 않습니다. 공 따라보기와 바운스볼은 보조 활동·일반 게임으로서 시선 안정화 재활을 대체하지 않습니다.

완료한 세션만 별도 localStorage에 최대 200개 저장합니다. 기존 재활 운동 횟수와 합산하지 않습니다. 게임 페이지의 기록 내보내기로 JSON을 저장할 수 있습니다.
