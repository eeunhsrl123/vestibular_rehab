# 게임 공간 설계와 실행 계획

요청: 세 가지 게임 구현 후 GitHub 커밋·푸시. 기존 정적 사이트와 현재 브라우저 기록 보존.

## 설계
별도 games.html 페이지에 모드 선택, 고정된 게임 장면, 시간·속도 설정, 시작·일시정지·즉시 중단, 세션 기록 제공. 기존 청록색과 잔디색을 유지하고 공은 노란색으로 대비. 카메라 이동·화면 흔들림·점멸 없음. 모바일 터치와 키보드 지원.

- 고정 표적: 세션 중 A가 있는 공 고정. 전문가에게 배운 머리 움직임을 사용자가 수행. 자동으로 수행 정확도를 측정하지 않음. 완료 후 사용자가 다음 발판 버튼을 누를 때만 공 이동.
- 공 따라보기: 머리 움직임 없이 눈으로 따라보는 별도 보조 활동. 느린 좌우/상하 이동과 속도 선택. 시선 안정화 재활 대체 불가 표시.
- 바운스볼: 고정된 화면에서 자동으로 뛰는 공을 좌우로 조작해 발판 위 별 수집. 낙하 시 시작점으로 복귀하며 벌점 없음. 일반 게임으로 분류.
- 모든 모드: 자동 시작 없음, 시작 전 안전 환경 확인, 화면을 떠나면 일시정지, 즉시 중단 시 미완료 처리, 완료한 세션만 별도 게임 기록 저장. 점수를 의학적 회복 정도로 표시하지 않음.

## 구현 순서
1. game-core.mjs: 세션 상태, 공 이동, 발판 충돌·별 수집 순수 로직. tests/game.test.mjs에 일시정지·완료 1회·낙하·충돌·반복 수집 방지 테스트 후 구현.
2. games.html/games.css/game.mjs: 세 모드와 기록, 입력·접근성·리사이즈 구현. 기존 index.html에 게임 진입 링크.
3. 전체 Node 테스트·구문 검사·브라우저 데스크톱/모바일 점검. 기존 사이트 dist에도 동기화하고 Sites 비공개 배포. GitHub main에 fast-forward 후 푸시.

## 검증 중점
숨겨진 탭 시간 누적 방지, 모드 변경 시 이전 세션 누출 방지, 반복 프레임 완료 중복 방지, 발판 착지, 중단 세션 미저장, 저장 차단 안내. 게임 기록은 기존 운동 처방 기록과 구분.
